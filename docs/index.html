01 / OVERVIEW

A clean foundation,
ready for ideas.

The first release keeps things deliberately simple: a conventional plugin layout, one Lua module, and one Neovim command. That makes it easy to understand today and easy to evolve tomorrow.

A

Native Neovim command

Run :NotRaycastHello from command mode and get an instant notification.

B

Lua from the start

A small, readable module with no compatibility layer and no runtime dependencies.

C

Built in public

The roadmap, issues, releases, and source stay visible as the product takes shape.

02 / INSTALL

Hello in under
a minute.

Add the plugin to your lazy.nvim setup, restart Neovim, and run the command. Neovim 0.8 or newer is recommended.

  1. 1
    Add the specPlace it with your other lazy.nvim plugins.
  2. 2
    Sync or restartLet lazy.nvim download the repository.
  3. 3
    Say helloRun :NotRaycastHello.
lazy.nvim lua/plugins/notraycast.lua 
-- Your lazy.nvim plugin spec
{
  "sunnybharne/notraycast.vim",
  cmd = "NotRaycastHello",
}
: NotRaycastHello
