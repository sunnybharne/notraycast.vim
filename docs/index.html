01 / OVERVIEW

One source.
One picker.

The plugin reads Firefox's local history database, gives the results to Telescope, and opens the selected URL. Nothing more.

A

Telescope-native search

Run :NotRaycastHistory and fuzzy-search page titles and URLs.

B

Local by design

History goes directly from Firefox's SQLite database to Telescope.

C

Simple on purpose

One direct Lua module, one command, and no custom interface.

02 / INSTALL

Search in under
a minute.

Add the plugin to lazy.nvim, close Firefox so its history database can be read safely, and run the command. Neovim 0.10 or newer is required.

  1. 1
    Add the specPlace it with your other lazy.nvim plugins.
  2. 2
    Sync and close FirefoxLet lazy.nvim install it, then release Firefox's history database.
  3. 3
    Search historyRun :NotRaycastHistory.
lazy.nvim lua/plugins/notraycast.lua 
-- Your lazy.nvim plugin spec
{
  "sunnybharne/notraycast.vim",
  dependencies = {
    "nvim-lua/plenary.nvim",
    "nvim-telescope/telescope.nvim",
  },
  cmd = "NotRaycastHistory",
}
: NotRaycastHistory
