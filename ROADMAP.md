# Roadmap

notraycast.vim will evolve in small, testable releases. The roadmap is
intentionally directional rather than a promise of dates or exact features.

## Foundation — current

- [x] Create a loadable Neovim plugin.
- [x] Add a first user command and public Lua function.
- [x] Add automated smoke testing and project documentation.
- [x] Add a minimal Telescope picker for Firefox history.

## Exploration — next

- [x] Define Firefox history search as the first experimental workflow.
- [ ] Read current history safely while Firefox is open.
- [ ] Explore bookmarks and other deliberately chosen sources.
- [ ] Decide whether a general action registry is actually needed.
- [ ] Establish configuration and extension APIs.

## Productization — later

- [ ] Add help documentation available through `:help notraycast`.
- [ ] Expand automated tests across supported Neovim versions.
- [ ] Document compatibility and performance expectations.
- [ ] Publish stable releases with migration notes.

Suggestions are welcome through
[GitHub Discussions](https://github.com/sunnybharne/notraycast.vim/discussions)
or feature requests.
